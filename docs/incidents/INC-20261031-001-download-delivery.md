## 影响与证据边界

用户先后遇到“无法确认下载连接的控制关系”、大原画低速/停流后失败、文件已保存但页面仍显示结果未确认。本地与生产还出现同作品默认43 MB压缩4K和523 MB原画的差异。不能把这些症状合并归因为SW。

目标原画为 **523,069,472字节、2160×3840、HEVC、视频123.651秒，含AAC立体声音轨**。43,074,063字节压缩4K属于另一份文件。影响已在这些已记录任务中确认，没有依据宣称九平台或所有用户均失败。

普通媒体链路为：PHP向平台获取详情/调度地址；随后**媒体CDN → 用户浏览器Worker → 下载管理器 → 文件**。同源bridge维持控制关系，不转发媒体；任务存储只保存轻量身份与状态。API成功、容器头尾探测成功、可播放、页面完成和实际完整保存是不同证据层级。

## 防复发执行规则

1. **先定义成功与停止。** 任务开始先写本轮要确认的行为、唯一变量、最多尝试次数和时间/流量预算。正常正式路径完整保存并达到当前验收要求后停止；不要为了补测速表、归档或解释全部历史异常再次下载。
2. **先核输入再比较。** 记录作品及实际文件的大小、尺寸、编码、时长、URL摘要、取得时刻和已知/推定有效期；不公开签名URL。剩余窗口须覆盖预计测试预算，不能把未知有效期写成有效。仅一轮内固定精确URL，优先在取得后5分钟内完成；窗口不够就不开该轮。第一笔正式GET必须成功且读到媒体才进入性能统计；403/0 B立即退出测速，不自动续轮。若需新来源，按现有授权正常解析并重开有明确边界的一轮，不混用前后样本。
3. **确认实际执行者与路径。** 当前播放器不代表旧任务快照；记录正式任务的构建/Worker和实际URL。需要归因网络时才采集进程、连接端口/IP、协议和实际出站；配置DIRECT或curl未设代理不等于绕过TUN。不能把代理入口、Fake-IP当CDN端点。
4. **隔离工具影响，复用已完成事实。** 网络已完成但工具暂停文档时，先解除该观测干扰；未经确认不得把它归因为用户未操作。文件已保存先核可信终态，已有保存/哈希不重复下载；用户额外点击、诊断取消、自然失败分别记录。工具缺失权限不改用未授权方式绕过。
5. **最小修复、分层交付。** 只有“原条件失败、单一修正后恢复”或确定性代码反例才支持对应修复。无新证据不改SW、IndexedDB、超时、画质或全局网络。区分用户报告、模块测试、实际HTTP、浏览器保存，以及已上线/待发布；没有可信参考只写已计算哈希。每次报告同步当前结论，保留原失败和证据限制。

**方案一：不采用“-ov”硬过滤。** 现有证据只证明特定v5来源慢、特定v3来源快，没有抖音公开合同保证后缀一定表示地域或速度。当前原画只有这个source，删除后可能丢失原画或默认退到43 MB压缩4K。

有上游真实提供的、经验证属于**同一原画文件**的多个来源时，可以调整后端默认source优先级；完整候选继续保留，用户显式选择与已有任务快照不变，前端不增加画质排序。主机标记至多是辅助信号，不能替代可用性与线路证据；无等价替代时不悄悄降级。

**方案二：优先验证相关解析请求的国内/香港出口。** 出口及DNS等上下文可能影响302调度；大陆与香港不应视为同一调度区，地理接近也不保证更快。一般CDN会综合位置、运营商与节点健康选择线路（[Alibaba Cloud CDN原理](https://www.alibabacloud.com/help/en/cdn/product-overview/what-is-alibaba-cloud-cdn)）；这是一般依据，不是抖音内部实现证明。

只改变抖音详情/原画入口解析出站，媒体仍CDN→用户浏览器。当前`SnapMediaProbe::request`显式禁用环境代理并绑定DNS结果，单设全局HTTP_PROXY不会改变这条路径；实际实施应是明确的平台出站策略，保留HTTPS/TLS、公网地址、跳转与字节预算，不能变成全站代理或媒体中转。

下一轮固定作品、原画入口、UA/头部、代码及预算，只比较现有出口与一个候选出口，每边一次有界请求；记录真实出口/DNS、最终主机、URL摘要与媒体规格。确认等价可交付来源后，在同一用户网络做一次正式完整保存。出口不存在或需改全局DNS/TUN时先明确具体配置与影响，不直接切换现网。上述均为评估，本次未实施选源或出站变更。

## 原画入口直接交给浏览器的可行性（2026-10-31）

既有生产Origin试验使用`GET + Range: bytes=0-65535`，入口302没有跨域许可，未取得媒体字节；它不能证明无Range或原生导航也失败。因此本轮只补一次无Range请求：Edge156、`https://snap.dokitool.com` Origin，同一个冻结的原画入口（URL SHA-256 `c8ce892f6c061a905e76025a7e123045351923b0818efb27d4e2b056b486b0fc`），与正式SW一致的`mode:cors`、`credentials:omit`、`referrerPolicy:no-referrer`；不重新解析、不手改CDN、不重试。诊断预算8秒或读取64KiB后取消，没有启动下载任务。

结论边界：当前入口不能直接作为已验证可读的SW/Blob默认来源。`no-cors`响应体不可供JavaScript读取，`redirect:manual`也不会向页面暴露跨域Location（[MDN响应类型](https://developer.mozilla.org/en-US/docs/Web/API/Response/type)）。直接导航入口是另一条能力，可能跳转播放或由浏览器下载，但未在本轮验证，且不能保证作品命名和页面进度；不能将其导航可用性冒充当前紫色按钮全流程通过。服务器探测的文件属性也不能直接保证客户端重新调度后仍为相同文件。只保留入口为候选不自动解决这些条件，不据此调整default或删除原画。
